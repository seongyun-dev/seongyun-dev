# 안성윤 (An SeongYun)

### 현장 경험을 데이터 기반 운영 개선으로 연결합니다

냉동공조공학과를 졸업하고 안전관리 실무를 경험했습니다. 현재 SSAFY에서 소프트웨어와 데이터 분석 역량을 쌓으며, 현장의 맥락과 데이터를 함께 살펴 실행 가능한 개선으로 연결하는 FDO·데이터 분석 직무를 지향합니다.
